# 长图切片

把横向长图裁成一组等宽图片，方便在抖音按顺序分享。支持 Android 10 及以上。

**[下载长图切片 1.1（安卓 APK）](https://github.com/zunranmeng-byte/photocut/releases/download/v1.1/PhotoCut-1.1.apk)** · [版本说明](https://github.com/zunranmeng-byte/photocut/releases/tag/v1.1)

1. 下载后，在手机的文件管理器里打开 APK 安装。如果系统提示允许当前来源安装应用，按手机提示操作。
2. 打开「长图切片」，选一张横向长图。拖动裁剪窗，选择按张数或按比例裁切。
3. 点「预览切片」→「一键保存全部」。也可以逐张保存。
4. 在抖音的相册里打开 **PhotoCut**，按 **01、02、03…** 依次选图。

图片在手机本地处理。批量保存从右到左写入，方便按从新到旧的顺序找到第一张。PNG 切片可以按编号无缝拼接。
